# C++ Game Development Collection 🎮

A repository showcasing my journey in building logic-based games using C++. This collection focuses on fundamental programming concepts, algorithm design, and user interaction in a console environment.

## 🚀 Projects Included

### 1. Guess the Number
A classic logic game where the computer selects a random number, and the player has to guess it within a limited number of attempts.
* **Key Concepts:** Random number generation, loops, and conditional logic.

## 🛠️ Tech Stack
* **Language:** C++
* **Compiler:** G++ / Clang
* **Environment:** Visual Studio Code (macOS)

## 📖 How to Run
1. Clone the repository: 
   `git clone https://github.com/gourav09-cyber/Learning-Journey.git`
2. Navigate to the project folder.
3. Compile the file:
   `g++ guessthenumber.cpp -o GuessGame`
4. Run the executable:
   `./GuessGame`
